# claude-test

Claude 各模型在同一类任务上的输出对比。**每个模型一个目录**，目录名即模型名，目录内放该模型的成品、脚本和说明。

| 目录 | 模型 | 内容 |
| --- | --- | --- |
| [`sonnet-5.5/`](sonnet-5.5/) | Claude Sonnet 5.5 | 鳄鱼骑自行车 SVG 动画 |
| [`opus-5.5/`](opus-5.5/) | Claude Opus 5.5 | 鳄鱼骑自行车 SVG 动画 |
| [`fable-5.2/`](fable-5.2/) | Claude Fable 5.2 | 鳄鱼骑自行车 SVG 动画（三轮结果都保留） |

新增其他模型的结果时，请新建同级目录（例如 `opus-5.5/`），不要覆盖已有目录。
